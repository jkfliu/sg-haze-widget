SG Haze widget

A home screen and lock screen widget with the latest PM2.5 and PSI for your part of Singapore, plus a chart of PM2.5 over the last 24 hours. The readings come from NEA through data.gov.sg.

Set it up

  1. Install Scriptable

    Get Scriptable from the App Store. It's free and runs small scripts like this one.

  2. Copy the script

    Open this page on your iPhone and tap the button.

    Show the script

    If the button doesn't work, open Show the script, tap inside the box, then Select All and Copy.

    The script didn't load. Open the script on GitHub, then long-press the text, tap Select All and Copy.

  3. Paste it into Scriptable

    Open Scriptable, tap + and paste. Tap the title at the top, rename it SG Haze, then tap Done.

  4. Add the widget

    • Home screen: long-press an empty spot, tap Edit → Add Widget, choose Scriptable, pick small or medium, and add it. Long-press the new widget, tap Edit Widget, and set Script to SG Haze.
    • Lock screen: long-press the lock screen, tap Customize, then the lock screen. Tap the widget area under the clock and add Scriptable's rectangular widget. Close the widget gallery, then tap the widget itself to set Script.

  5. Pick your region

    In the same panel, type your region into Parameter. Tap a name to copy it:

    Leave it blank for central. Anything it doesn't recognise also shows central, so check the region name at the top of the widget. Each widget has its own setting, so you can add one per region.

Reading the widget

PM2.5 1h is the latest one-hour reading in µg/m³, and the chart shows the last 24 hours of it. PSI 24h is the 24-hour Pollutant Standards Index. The dots use these bands:

PM2.5 (µg/m³)BandPSIBand
0–55Normal0–50Good
56–150Elevated51–100Moderate
151–250High101–200Unhealthy
251+Very High201–300Very Unhealthy
301+Hazardous

For health advice, tap the widget to open haze.gov.sg.

Good to know

"Updated 3:00pm" is the hour of the reading. NEA publishes each hour's reading about 45 minutes later, and the widget asks iOS to refresh at 50 minutes past each hour. iOS decides the exact timing, so it can be later.

"⚠ stale" means the reading is over two hours old. This usually happens when your phone was offline or iOS hasn't refreshed the widget for a while.

"↑ update" means a new version is available. Open SG Haze in Scriptable and tap Install update. You'll see what changed first. Nothing installs by itself. The update comes from the project on GitHub, and you can turn update checks off in the same menu.

The app always shows central. When you run SG Haze inside Scriptable, it doesn't read a widget's Parameter. Only the widgets use your region.
